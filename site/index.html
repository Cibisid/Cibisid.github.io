LLM Gateway

One OpenAI-compatible endpoint that routes requests across model providers and fails over when one goes down.

Problem. Apps tied to one provider break during its outages, and every team rebuilds tool access.

Built. Alias routing with fallback order, an MCP server with 11 tools, and agent-to-agent delegation.

Result. 167 tests passing and a 23-case evaluation suite.

Stack Python · FastAPI · MCP · A2A · Docker

ShippedHealthcare AI

TrialBridge

Matches patients to clinical trials, with an agent that says UNKNOWN instead of guessing.

Problem. Each trial has dozens of eligibility rules, and a confident wrong match is dangerous.

Built. Vector search over ClinicalTrials.gov plus a Claude agent on Amazon Bedrock that checks rules with tools.

Result. 2,344 trials indexed, 86 tests, CI passing.

Stack Python · pgvector · sentence-transformers · Bedrock
